Talking About Time: In a Bit, Right Away, Later, Long Ago

「一jat1陣zan6間gaan1」同tung4「遲ci4啲di1」有jau5幾gei2遲ci4？「一jat1早zou2」又jau6係hai6幾gei2早zou2？學hok6識sik1呢ne1幾gei2個go3講gong2時si4間gaan3嘅ge3常soeng4用jung6口hau2語jyu5，約joek3人jan4做zou6嘢je5唔m4會wui5搞gaau2錯co3。

How late is 'jat1 zan6 gaan1' versus 'ci4 di1'? Learn these common Cantonese time expressions so you never mix up plans.

俚語日常會話入門

一jat1陣zan6間gaan1 —— 等dang2一jat1會wui6、過gwo3一jat1陣zan6

我ngo5一jat1陣zan6間gaan1打daa2返faan1畀bei2你nei5。
我等一下回你电话。
I'll call you back in a bit.

即zik1刻hak1 —— 馬maa5上soeng6

收sau1到dou2，我ngo5即zik1刻hak1去heoi3。
收到，我马上去。
Got it, I'm going right away.

遲ci4啲di1 —— 過gwo3一jat1排paai4、之zi1後hau6

遲ci4啲di1得dak1閒haan4再zoi3約joek3。
以后有空再约。
Let's meet up later when we're free.

「遲ci4啲di1」冇mou5講gong2明ming4幾gei2時si4，有jau5時si4係hai6客haak3氣hei3說syut3話waa6，唔m4一jat1定ding6真zan1係hai6會wui5約joek3。

一jat1早zou2 —— 早zou2就zau6、老lou5早zou2

我ngo5一jat1早zou2同tung4你nei5講gong2咗zo2。
我早就跟你说了。
I told you that ages ago.
