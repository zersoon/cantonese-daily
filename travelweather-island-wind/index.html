Strong Winds on an Island Trip: Big Waves, Sailing Times, Cancellations, the Last Boat

去heoi3離lei4島dou2玩waan2，最zeoi3驚geng1突dat6然jin4起hei2風fung1，船syun4期kei4可ho2能nang4會wui5取ceoi2消siu1。學hok6識sik1問man6尾mei5班baan1船syun4、講gong2大daai6浪long6，唔m4使sai2驚geng1冇mou5船syun4返faan2出ceot1市si5區keoi1。附fu6粵jyut6拼ping3。

On an outlying island trip, the worry is wind picking up and sailings being cancelled. Learn to ask about the last boat and talk about big waves. With Jyutping.

大daai6浪long6 —— 大daai6浪long6

今gam1日jat6海hoi2面min6好hou2大daai6浪long6，船syun4搖jiu4得dak1好hou2犀sai1利lei6。
今天海面浪很大，船晃得很厉害。
The sea is really rough today, the boat is rocking a lot.

船syun4期kei4 —— 船syun4班baan1时si4间gaan3

出ceot1發faat3之zi1前cin4睇tai2定ding6船syun4期kei4，唔m4好hou2走zau2漏lau6船syun4。
出发前先看好船班时间，别错过了船。
Check the sailing times before you set off so you don't miss the boat.

取ceoi2消siu1 —— 取ceoi2消siu1

風fung1太taai3大daai6，下haa6晝zau3嘅ge3船syun4全cyun4部bou6取ceoi2消siu1咗zo2。
风太大，下午的船全部取消了。
The wind is too strong, all the afternoon sailings have been cancelled.

Excuse me, what time does the last boat leave?

返faan1唔m4到dou2出ceot1市si5區keoi1 —— 回wui4不bat1了liu5市si5区keoi1

如jyu4果gwo2停ting4船syun4，我ngo5哋dei6就zau6返faan1唔m4到dou2出ceot1市si5區keoi1。

If the ferries stop, we won't be able to get back to the city.
